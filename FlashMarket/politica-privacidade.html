Política de Privacidade

Esta página apresenta, de forma resumida, como o FlashMarket trata dados necessários para conta, pedidos, pagamento e atendimento.

Dados utilizados

Podemos tratar nome, e-mail, telefone, dados de endereço e informações relacionadas aos pedidos quando necessários para executar os serviços solicitados.

Finalidades

Os dados são utilizados para autenticação, processamento de pedidos, acompanhamento de entrega, atendimento e segurança da plataforma.

Pagamentos

O pagamento é processado pelo Mercado Pago. O FlashMarket não deve solicitar ao cliente que informe senha de cartão diretamente no site.

Segurança

A plataforma utiliza HTTPS, autenticação por token e controles de acesso para proteger as operações.

Contato

Para dúvidas sobre privacidade, utilize a área de Atendimento.
