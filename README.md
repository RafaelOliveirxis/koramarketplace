## 📖 Sobre o projeto

O **FlashMarket** é uma plataforma de marketplace desenvolvida para simular uma experiência completa de comércio eletrônico. O projeto foi criado com foco em um layout moderno, responsivo e intuitivo, permitindo que a aplicação seja utilizada em computadores, tablets e smartphones.

A proposta reúne elementos comuns de grandes plataformas de e-commerce, como catálogo de produtos, busca, categorias, carrinho, favoritos, cupons, cashback, avaliações, acompanhamento de pedidos e área do usuário.

O projeto também possui estrutura preparada para evolução com API/backend e recursos adicionais.

## 🚀 Como executar localmente

### 1. Clonar o repositório

```bash
git clone https://github.com/RafaelOliveirxis/koramarketplace.git
```

### 2. Entrar na pasta

```bash
cd koramarketplace
```

### 3. Instalar as dependências

```bash
npm install
```

### 4. Executar o projeto

Para a versão estática do marketplace, abra:

```text
FlashMarket/index.html
```

Também é recomendado utilizar uma extensão como **Live Server** no VS Code para executar o projeto durante o desenvolvimento.
